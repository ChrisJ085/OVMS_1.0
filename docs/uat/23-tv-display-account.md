# UAT-23: TV Display Account

## Metadata
* **Test ID**: UAT-23
* **Requirement**: Validate that a dedicated non-interactive TV Display account opens the read-only dashboard directly without user input prompts.
* **Preconditions**: A dedicated monitor account `tv.barrow@gxo.com` with role `VIEWER` exists.

## Steps
1. Navigate to the login screen.
2. Sign in as `tv.barrow@gxo.com`.
3. Check the interface and interactivity of the dashboard.
4. Attempt to click on action buttons (e.g., Acknowledge, Start, Block, Edit Planning Rules, Create SKU).

## Expected Result
- The TV monitor lands directly on the optimized full-screen dashboard without showing secondary navigation, sidebars, or configuration panels.
- All action buttons are completely hidden or disabled, ensuring the dashboard remains read-only and tamper-proof.
